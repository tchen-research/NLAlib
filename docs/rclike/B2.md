The "reverse case" is new. Stage A described the forward problem (`HasOrthonormalCols` passed to a `ᵀ`
lemma). The mirror problem occurs when a real `Uᵀ * U = 1` proof is passed to a lemma whose
hypothesis is `HasOrthonormalCols U`. Lean solves `?Uᴴ * ?U = 1 =?= Uᵀ * U = 1` by unfolding, so
`U` is instantiated with an unfolded entry function and the later rewrite fails. It occurred four
times. Downstream agents should watch for it wherever `transpose_eigenvectorUnitary_mul_self hA`
or `h.mul_transpose_left` is passed straight into a `HasOrthonormalCols` slot.

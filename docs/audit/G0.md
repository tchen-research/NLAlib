### A1. `courant-fischer`: Courant–Fischer in subspace form, real symmetric (tin 11)

Statement: for symmetric `A`, the k-th largest eigenvalue `λ_k` (zero-indexed) satisfies two bounds.
If the Rayleigh quotient is at most `c` on a subspace of codimension at most `k`, then `λ_k ≤ c`.
If it is at least `c` on a subspace of dimension at least `k+1`, then `c ≤ λ_k`.

Lean-ready, in `NLAlib/Matrix/CourantFischer.lean` (the module name already reserved in `NLAlib/Matrix.lean`):

```lean
/-- SCAFFOLD: courant-fischer. Min-max upper half (Horn–Johnson 2013, Thm 4.2.6, subspace form;
HJ orders eigenvalues increasingly, here `eigenvalues₀` is decreasing and zero-indexed). -/
theorem eigenvalues₀_le_of_forall_mem {n : Type*} [Fintype n] [DecidableEq n] {A : Matrix n n ℝ}
    (hA : A.IsHermitian) (k : Fin (Fintype.card n)) (W : Submodule ℝ (n → ℝ))
    (hW : Fintype.card n ≤ Module.finrank ℝ W + k) {c : ℝ}
    (hAW : ∀ x ∈ W, x ⬝ᵥ (A *ᵥ x) ≤ c * (x ⬝ᵥ x)) :
    hA.eigenvalues₀ k ≤ c

/-- SCAFFOLD: courant-fischer. Max-min lower half (HJ13 Thm 4.2.6). -/
theorem le_eigenvalues₀_of_forall_mem {n : Type*} [Fintype n] [DecidableEq n] {A : Matrix n n ℝ}
    (hA : A.IsHermitian) (k : Fin (Fintype.card n)) (S : Submodule ℝ (n → ℝ))
    (hS : (k : ℕ) + 1 ≤ Module.finrank ℝ S) {c : ℝ}
    (hAS : ∀ x ∈ S, c * (x ⬝ᵥ x) ≤ x ⬝ᵥ (A *ᵥ x)) :
    c ≤ hA.eigenvalues₀ k
```

Companion lemmas, provable now with no `sorry`: the attaining subspaces. These are the span of
eigenvectors `0..k`, and the span of eigenvectors `k..`, both from `Matrix.IsHermitian.eigenvectorBasis`.
The statement is
`∃ S, finrank S = k+1 ∧ ∀ x ∈ S, λ_k (x⬝x) ≤ x⬝Ax`, together with the dual for `W`.

- **Mathlib:** absent. Grep for `courant`, `min-max`, `interlac` and `eigenvalues_le` finds nothing. Mathlib has
  only the extreme cases: `LinearMap.IsSymmetric.hasEigenvalue_iSup_of_finiteDimensional` and
  `ContinuousLinearMap.norm_eq_iSup_rayleighQuotient` in `Analysis/InnerProductSpace/Rayleigh.lean`.
  It also has the sorted eigenvalues `Matrix.IsHermitian.eigenvalues₀` with `eigenvalues₀_antitone`.
- **Source:** Horn–Johnson 2013, Thm 4.2.6.
- **Confidence:** high. Points that could be subtly wrong:
  - the index convention: zero-indexed and decreasing, while HJ is 1-indexed and increasing;
  - the dimension conditions are written additively (`card ≤ finrank W + k`, `k+1 ≤ finrank S`) to
    avoid ℕ subtraction;
  - no sign condition on `c` is needed, because both subspaces are nonzero since `k < card n`.
- **Statement deviation from the atlas:** the entry lists `uses_defs` `NLAlib.lambdaMax`/`lambdaMin` (complex,
  `Concentration`, layer 1) and `NLAlib.quadForm` (`Estimation`, layer 4). A layer-0 theorem cannot use
  either, so the statement spells `x ⬝ᵥ (A *ᵥ x)` and uses `eigenvalues₀`. I recommend moving
  `quadForm` down to `Matrix/Norms.lean`, so it is a single spelling usable everywhere.
- **Unlocks:** `weyl-mirsky`, `eckart-young` (spectral), `cauchy-interlacing`, then `hutchpp`,
  `truncation-lemma`, `volume-sampling` and `rpcholesky`. It also unlocks the singular-value form (B1) and Loewner
  monotonicity of eigenvalues (B8).
- **Full proof:** difficulty 2–3, so try to prove it before scaffolding. The method is the dimension count
  `Submodule.finrank_sup_add_finrank_inf_eq`, then expansion in `eigenvectorBasis`, giving
  `x⬝Ax = Σ λ_i ⟨b_i,x⟩²`.

### A2. `von-neumann-trace`: the full von Neumann trace inequality (unlocks the Mirsky half of `weyl-mirsky`, tin 6)

Statement: `⟨X, E⟩_F ≤ Σ_i σ_i(X) σ_i(E)`.

Lean-ready, in `NLAlib/Matrix/Trace.lean` (also reserved in `NLAlib/Matrix.lean`):

```lean
/-- SCAFFOLD: von-neumann-trace. Von Neumann trace inequality (Horn–Johnson 2013, Thm 7.4.1.1;
real case, `Re tr(X Eᴴ) = frobInner X E`). -/
theorem frobInner_le_sum_singularValues_mul {m n : ℕ} (X E : Matrix (Fin m) (Fin n) ℝ) :
    frobInner X E ≤ ∑ k ∈ Finset.range (min m n), singularValues X k * singularValues E k
```

- **Mathlib:** absent. Grep for `vonNeumann`, `von Neumann trace`, `Ky Fan`, `Mirsky` finds nothing relevant. Mathlib has the
  ingredients for a proof: Birkhoff (`doublyStochastic_eq_convexHull_permMatrix` in
  `Analysis/Convex/Birkhoff.lean`) and rearrangement (`Monovary.sum_mul_comp_perm_le_sum_mul`).
- **Source:** HJ13 Thm 7.4.1.1.
- **Confidence:** high. There are no degenerate-case issues: `σ_k = 0` for `k ≥ min m n`, so summing over `range (min m n)`
  is the full sum.
- **Unlocks:**
  - `weyl-mirsky`, the Frobenius half (B4);
  - nuclear/spectral norm duality, which is new;
  - the `hVN` corollary, although C4 proves that corollary directly without this.
- **Full proof:** difficulty 3. A route that avoids Birkhoff:
  1. Ky Fan: `tr(U_kᵀ E V_k) ≤ Σ_{i≤k} σ_i(E)` for orthonormal `U_k, V_k`. This is the same weighted
     top-k inequality as the existing private `weighted_sum_le_head` in `Matrix/EckartYoung.lean`, so that
     lemma should be made public.
  2. Abel summation over `σ_k(X) − σ_{k+1}(X)`.

### A3. `bernstein-ellipse-approx`: analytic functions on a Bernstein ellipse (tin 1)

Statement: if `f` is analytic on the open Bernstein ellipse `E_ρ` with `|f| ≤ M` there, then
`min_{deg p ≤ q} ‖f − p‖_{[-1,1]} ≤ 2Mρ^{−q}/(ρ−1)`.

Lean-ready, in a new file `NLAlib/Polynomial/Analytic.lean`:

```lean
/-- The open Bernstein ellipse with foci `±1` and parameter `ρ` (semi-axes sum `ρ`). -/
def bernsteinEllipse (ρ : ℝ) : Set ℂ := {z | ‖z - 1‖ + ‖z + 1‖ < ρ + ρ⁻¹}

/-- SCAFFOLD: bernstein-ellipse-approx. Trefethen, ATAP (2019), Thm 8.2 (Chebyshev projection bound).
Deviation: stated for `Re f` so that the approximant is a real polynomial. -/
theorem exists_degree_le_abs_sub_eval_le_of_bernsteinEllipse {ρ M : ℝ} (hρ : 1 < ρ)
    {f : ℂ → ℂ} (hf : DifferentiableOn ℂ f (bernsteinEllipse ρ))
    (hM : ∀ z ∈ bernsteinEllipse ρ, ‖f z‖ ≤ M) (q : ℕ) :
    ∃ p : Polynomial ℝ, p.degree ≤ q ∧ ∀ x ∈ Set.Icc (-1 : ℝ) 1,
      |(f x).re - p.eval x| ≤ 2 * M * ρ⁻¹ ^ q / (ρ - 1)
```

- **Mathlib:** absent. Grep for `Bernstein ellipse`, `bernsteinEllipse`, `Joukowsk` finds nothing. Mathlib has
  `Polynomial.Chebyshev.T_complex_cos` and the Cauchy integral (`circleIntegral_sub_inv_smul`).
- **Source:** Trefethen 2019 Thm 8.2. UCS17 Thm 4.1 is the SLQ form.
- **Confidence:** high. Points to check:
  - The ellipse is open, with focal-distance sum `ρ+ρ⁻¹ = 2a`.
  - The approximant is the Chebyshev truncation of degree `q`.
  - Taking `Re` is harmless, since `|Re w| ≤ |w|` and the real part of a complex polynomial is real on ℝ.
  - The interpolant version has constant `4M` instead of `2M`, and is a separate corollary.
- **Unlocks:** `slq-error` (G3). The affine rescaling to `[a,b]` is a B-level corollary.
- **Full proof:** difficulty 4. It needs Chebyshev coefficients as contour integrals through the Joukowski map.

### Assumed or scaffold statements, and atlas metadata, that are wrong or non-standard

1. **`von-neumann-trace` conflates two statements.** The atlas marks it `assumed` via the LRA declaration
   `VonNeumannRankBound`, but that declaration is only the rank corollary
   `⟨X,E⟩ ≤ √r‖X‖_F‖E‖`. It is correct, but it is not the trace inequality. Proposed fix:
   - catalogue the corollary separately and prove it now (C4);
   - rewire `tgn-expected-error` to the corollary;
   - leave `von-neumann-trace` as the full inequality: candidate now, scaffold under A2.
2. **`hmt-9-1-spectral`: the statement is correct, but its premises are redundant and it has a spurious edge.**
   - `HMTSpectralBound` assumes `HasOrthonormalCols U₁`, `U₁ᵀU₂ = 0` and `V₁V₁ᵀ+V₂V₂ᵀ = 1`, and the proof uses none of them.
   - It is stated over `Fin` (STANDARDS §3 asks for `Fintype`).
   - The atlas `depends_on` lists `weyl-mirsky`, but the proof (C2) does not use it. Remove the edge, or replace it by
     `norms-frob-spec`. As it stands, the edge wrongly makes an open node a prerequisite.
3. **`randomized-kaczmarz` is `proved` but depends on `courant-fischer`, which is a candidate.** The formalization takes
   `hσ : ∀ v, σ² v⬝v ≤ (Av)⬝(Av)` directly (see the usage note of `Kaczmarz.expErr_le`), so the edge is spurious.
   Replace it with `norm-lipschitz` (`sigmaMin`).
4. **`courant-fischer` `uses_defs` crosses layers.** It lists `lambdaMax`/`lambdaMin` (complex, layer 1) and `quadForm`
   (layer 4), so the Matrix-layer statement cannot use them; see A1. Suggested fix: move `quadForm` to `Matrix/Norms.lean`.
5. **Source labels to verify:**
   - `cauchy-interlacing` cites HJ13 Thm 4.3.17, which I believe is the bordered/principal-submatrix
     form. The compression form `QᵀAQ` stated in the atlas is the Poincaré separation theorem, which I believe is
     HJ13 Cor 4.3.37.
   - `weyl-mirsky` cites "Thm 7.4.9.1" for Mirsky. Check that label against HJ13; Bhatia 1997 Thm IV.3.4 / §III.6

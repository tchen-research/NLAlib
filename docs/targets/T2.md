## 4. Candidates

Notation: `a_k` Chebyshev coefficients, `f_n = Σ_{k≤n} a_k T_k`, `p_n` the interpolant in the `(n+1)`-point
Chebyshev grid `cos(jπ/n)`, `E_ρ` the open Bernstein ellipse, `E_n(f;[a,b])` the best uniform error, `φ` the
affine map `[−1,1] → [a,b]`. "Prove" or "assume" follows CONTRIBUTING § "Assuming is encouraged".

### Definitions

**D1 `chebyshev-coefficients-def`: Chebyshev coefficients and truncation.** (`now`, difficulty 2, prove)
`a_k(f) = (2/π)∫_0^π f(cos θ) cos kθ dθ` (`1/π` for k = 0), `f_n = Σ_{k≤n} a_k T_k`. Characterisations:
`a_k = (2/π)∫ f T_k dmeasureT`; linear; `a_k(T_m) = δ_km`; exact on polynomials of degree ≤ n; `|a_k| ≤ 2 max|f|`.
Source: Trefethen ATAP Ch. 3 (formula in Thm 3.1). Mathlib has the weight measure, the cos substitution and
orthogonality. It lacks the coefficient functional; the Orthogonality file's TODO is the HilbertBasis. Consumers: all of
`polynomial-series`, KPM, Chebyshev-interpolation trace estimators.

**D2 `bernstein-ellipse-def`: Bernstein ellipse.** (`now`, 2, prove)
`E_ρ = {z : |z−1| + |z+1| < ρ + ρ⁻¹}` = Joukowski image of `ρ⁻¹ < |w| < ρ`. Characterisations: open, monotone,
`[−1,1] ⊆ E_ρ`; on the closure, `|z| ≤ (ρ+ρ⁻¹)/2`, `Re z ≥ −(ρ+ρ⁻¹)/2`, `|T_n(z)| ≤ (ρⁿ+ρ⁻ⁿ)/2`; affine image for
`[a,b]` with `Re z ≥ ((b+a) − (b−a)(ρ+ρ⁻¹)/2)/2`. Source: ATAP Ch. 8. Mathlib: `T_complex_cos`; there is no ellipse.
Consumers: 8.1, 8.2, `bernstein-ellipse-approx`, Bernstein's growth lemma, the slit-plane approximations, the analytic quadrature bound, T1.

**D3 `minimax-error-def`: E_n(f; [a,b]).** (`now`, 2, prove)
`E_n = sInf {E | ∃ p, deg p ≤ n ∧ ∀ x ∈ [a,b], |f x − p x| ≤ E}`, in the `IsLeast` style of `isLeast_chebyshev_minimax`.
For continuous f it is attained, antitone in n, tends to 0, invariant under adding polynomials of degree ≤ n, absolutely
homogeneous, subadditive and invariant under affine change of variable. Source: ATAP Ch. 10; Cheney Ch. 1. Mathlib: Weierstrass
(`exists_polynomial_near_of_continuousOn`) and compactness (`IsCompact.exists_isMinOn`). It has no proximinality lemma.
Theorems keep NLAlib's existential form; E_n is for statements whose sharp form needs the infimum. Consumers:
Lebesgue, de la Vallée Poussin, equioscillation, Jackson, and the δ_k of Musco–Musco–Sidford 2018 (T1).

**D4 `lebesgue-constant-def`: Lebesgue function and constant, with ATAP Thm 15.1.** (`next`, 2, prove)
`λ(x) = Σ_j |ℓ_j(x)|`, `Λ = max_{[a,b]} λ`. Characterisations: `Λ ≥ 1`; Λ is the operator norm of interpolation;
**near-best**: `max|f − p| ≤ (1 + Λ) E_n(f)` (Thm 15.1). Mathlib: `Lagrange.basis`, `sum_basis`, `eq_interpolate`.
Consumers: `lebesgue-constant-chebyshev`. It also turns E_n bounds into bounds for computable interpolants, e.g. at
`chebyshevZero` for Chebyshev-interpolation spectral-sum estimators (Han–Malioutov–Avron–Shin 2017).

### Chebyshev series (`polynomial-series`)

**`chebyshev-series-convergence` (ATAP Thm 3.1).** (`next`, 3, prove (a), assume or defer (b))
(a) If f is continuous and `Σ|a_k| < ∞`, then `f = Σ a_k T_k` pointwise and `max|f − f_n| ≤ Σ_{k>n}|a_k|`.
(b) If f is Lipschitz, then (a) holds and the series is unique. Mathlib: `has_pointwise_sum_fourier_series_of_summable`
applied to `θ ↦ f(cos θ)` on `AddCircle (2π)`, whose Fourier coefficients are `a_|k|/2`. Bernstein's theorem for (b)
is missing. (b) has no consumer that 7.1 and 8.1 do not already cover. Consumers: 4.2, 7.2, 8.2.

**`chebyshev-aliasing` (ATAP Thms 4.1–4.2).** (`next`, 3, prove)
On `x_j = cos(jπ/n)` (Mathlib `node`), `T_m = T_{2ℓn±m}`. Interpolant coefficients:
`c_0 = a_0 + a_{2n} + …`, `c_n = a_n + a_{3n} + …`, `c_k = a_k + Σ_{ℓ≥1}(a_{2ℓn+k} + a_{2ℓn−k})`. Hence
`max|f − p_n| ≤ 2 Σ_{k>n}|a_k|`. Stated under summability rather than ATAP's Lipschitz, which avoids 3.1(b). First-kind
variant at `chebyshevZero`: `T_{2(n+1)−m} = −T_m` there. Mathlib's `integral_eq_sumZeroes` is the quadrature relative.
Consumers: the interpolant halves of 7.2 and 8.2.

**`chebyshev-coeff-bv-decay` (ATAP Thm 7.1).** (`next`, 4, assume; prove the C^{ν+1} corollary)
If `f,…,f^{(ν−1)}` are AC and `f^{(ν)}` has variation V, then `|a_k| ≤ 2V/(π k(k−1)⋯(k−ν))` for `k ≥ ν+1`. Mathlib has
`AbsolutelyContinuousOnInterval` with integration by parts and `BoundedVariationOn`. It lacks Stieltjes integration
against BV functions, which the last step needs. The simple form, with `f^{(ν+1)}` continuous and `V = ∫|f^{(ν+1)}|`, needs only AC
integration by parts. Consumers: 7.2; spectral sums of non-analytic f (Schatten-p, |x|^p).

**`chebyshev-approx-differentiable` (ATAP Thm 7.2).** (`next`, 2 given 7.1, prove)
For `ν ≥ 1`, `n > ν`: `‖f − f_n‖ ≤ 2V/(πν(n−ν)^ν)`, `‖f − p_n‖ ≤ 4V/(πν(n−ν)^ν)`. Consumers: SLQ and Hutch++ for
non-smooth f, smoothed spectral densities.

**`chebyshev-coeff-analytic-decay` (ATAP Thm 8.1).** (`now`, 3, prove)
If f extends to F analytic on `E_ρ` with `|F| ≤ M`, then `|a_0| ≤ M` and `|a_k| ≤ 2Mρ^{−k}`. Proof: `a_k = (1/πi)∮ F(J(w)) w^{−k−1} dw`
on `|w| = 1`; shift to `|w| = r < ρ` with `Complex.circleIntegral_eq_of_differentiable_on_annulus_off_countable`, bound,
let `r ↑ ρ`. Consumers: 8.2 and everything analytic below it.

**`chebyshev-approx-analytic` (ATAP Thm 8.2).** (`now`, 2 given 8.1, prove)
`‖f − f_n‖ ≤ 2Mρ^{−n}/(ρ−1)` and `‖f − p_n‖ ≤ 4Mρ^{−n}/(ρ−1)`, transplanted to `[a,b]`. The **stronger version** of the
existing `bernstein-ellipse-approx`: it names the polynomial (`f_n`, `p_n`) rather than just the infimum. That entry becomes its corollary.
Consumers: `bernstein-ellipse-approx`, `slq-error`, `lanczos-quadrature-analytic-error`, `slit-plane-analytic-approx`,
T1's `‖f(A)b − V f(H)e_1‖ ≤ 2‖b‖ min_p ‖f − p‖`.

### Best approximation (`polynomial-best`, plus one entry in `polynomial-chebyshev`)

**`de-la-vallee-poussin`.** (`next`, 2, prove)
If `f − p` (`deg p ≤ n`) alternates in sign at `x_0 < … < x_{n+1}`, then every q with `deg q ≤ n` has
`max_i |f(x_i) − q(x_i)| ≥ min_i |f(x_i) − p(x_i)|`, so `E_n(f) ≥ min_i |f(x_i) − p(x_i)|`. Source: Cheney Ch. 3;
ATAP Ch. 10. Proof: an n+1-root count (IVT, `card_roots'`). Consumers: equioscillation, explicit lower-bound
certificates. It generalises the lower half of `chebyshev-minimax`.

**`equioscillation` (ATAP Thm 10.1).** (`later`, 4, assume when needed)
For continuous real f, the best approximation is unique, and p is best iff `f − p` equioscillates at `n+2` points with
amplitude `max|f − p|`. The "if" direction is de la Vallée Poussin. Consumers: optimality statements
(`chebyshev-monic-minimal`, `chebyshev-minimax` are instances), Remez.

**`lebesgue-constant-chebyshev` (ATAP Thm 15.2).** (`later`, 4, assume)
For Chebyshev points `cos(jπ/n)`, `Λ_n ≤ (2/π)log(n+1) + 1`. With 15.1: `‖f − p_n‖ ≤ (2 + (2/π)log(n+1))E_n(f)`. The
first-kind analogue (`chebyshevZero`) has a bound of the same form (Rivlin); pin the label before stating it.

**`jackson-lipschitz` (Jackson's theorem III).** (`next`, 4, assume the sharp form)
If f is λ-Lipschitz on `[a,b]`, then `E_n(f) ≤ πλ(b−a)/(4(n+1))` (on [−1,1]: `πλ/(2(n+1))`, Favard's sharp constant).
Source: Cheney Ch. 4 §6; check the printed constant when stating. Mathlib has no rate for Weierstrass, since the Bernstein-polynomial
proof is qualitative. A worse explicit constant through the Jackson kernel is an acceptable first proof; the C^k version
(Cheney Thm V) is a later variant. Consumers: `lanczos-quadrature-lipschitz-error`, KPM, SLQ for non-smooth f.

**`bernstein-walsh-ellipse` (Bernstein's growth lemma)** in `polynomial-chebyshev`. (`next`, 2, prove)
If `deg p ≤ n` and `|p| ≤ M` on [−1,1], then `|p(z)| ≤ Mρⁿ` on `closure E_ρ`. This is the complex counterpart of NLAlib's real
`chebyshev-extremal`. Proof: `u^n p(J(u))` is a polynomial in u; apply maximum modulus on the unit disc. Consumers: the converse of 8.2
(ATAP Thm 8.3), complex-spectrum Krylov bounds (T1), and stability of Chebyshev recurrences (Musco–Musco–Sidford 2018).

### Bridges in `krylov`

**`lanczos-quadrature-analytic-error`.** (`next`, 1, prove)
For A symmetric with spectrum in `[a,c]`, `Q ⊇ K_q(A,b)` orthonormal, and `f∘φ` analytic in `E_ρ` with `|·| ≤ M`:
`|bᵀf(A)b − (Qᵀb)ᵀ f(QᵀAQ) Qᵀb| ≤ 4Mρ^{1−2q}/(ρ−1) · bᵀb`. Proof: NLAlib's
`abs_dotProduct_cfc_mulVec_sub_le_of_krylovSpace_le` plus 8.2 at degree `2q−1`. Consumer: `slq-error` for log-det,
tr exp, tr A^{−1/2} (ucs17 Thm 4.1).

**`lanczos-quadrature-lipschitz-error`.** (`next`, 1, prove once Jackson is assumed)
For L-Lipschitz f on `[a,c]`, the same quantity is `≤ πL(c−a)/(4q) · bᵀb`. For unit b this is
`W_1(μ_b, μ̂_q) ≤ π(c−a)/(4q)`. Stated with test functions because Mathlib has no Wasserstein distance. Consumers:
spectral density estimation (ctu21, bkm22).

### Specific functions and lower bounds (`polynomial-functions`)

**`monomial-chebyshev-approx` (Sachdeva–Vishnoi Thm 3.3).** (`now`, 2, prove)
`x^s = Σ_j 2^{−s} C(s,j) T_{|s−2j|}(x)`. Truncating to `|s−2j| ≤ d` gives degree ≤ d with error `≤ 2e^{−d²/(2s)}` on [−1,1].
The binomial tail is a cosh-Chernoff bound with no probability, because Polynomial is layer 0. Consumers: `exp-polynomial-approx`, the
"q Lanczos steps ≈ q² power steps" comparison (`random-start-power`, block Krylov vs subspace iteration).

**`exp-polynomial-approx` (SV Thm 4.1, constants derived).** (`next`, 2, prove)
Let `b > 0`, `0 < δ ≤ 1`, `t = ⌈max(e²b/2, log(2/δ))⌉` and `d = ⌈√(2t log(4/δ))⌉`. Then some p with `deg p ≤ d` has
`|e^{−x} − p(x)| ≤ δ` on `[0,b]`. SV state O(·). These constants come from their proof: Taylor truncation with Poisson tail
`(eb/2t)^t ≤ e^{−t}`, then the monomial approximation. For `e^{−τx}` on `[0,β]` take `b = τβ`. Consumers: heat-kernel
trace and Estrada index by SLQ or Hutch++, `exp(−τA)b` by Lanczos.

**`exp-approx-lower-bound`.** (`next`, 1, prove)
If `b ≥ 1`, `δ ≤ 1/8` and `|p − e^{−x}| ≤ δ` on `[0,b]` with `deg p ≤ q`, then `q² ≥ (1 − e^{−1} − 2δ) b / (2(1+δ))`, so
`q ≥ √(b/6)`. Proof: MVT on [0,1] plus NLAlib's interval Markov inequality. Source: SV §5 (method); constants derived here.

**`slit-plane-analytic-approx` (x^{−1/2}, log x, x^α on [a,b]).** (`now`, 2, prove)
Let `ρ_0 = (√b+√a)/(√b−√a)`, `1 < r < ρ_0`, `m_r = ((b+a) − (b−a)(r+r⁻¹)/2)/2 > 0` and `R_r = ((b+a) + (b−a)(r+r⁻¹)/2)/2`.
If F is analytic on `Re z > 0` and `|F| ≤ M` on `{Re z ≥ m_r, |z| ≤ R_r}`, then degree n reaches error `2Mr^{−n}/(r−1)` on `[a,b]`.
The constants are `M = max(m_r^α, R_r^α)` for `z^α` (so `m_r^{−1/2}` for `x^{−1/2}`) and `M = max(|log m_r|, |log R_r|) + π/2` for Log. This is ATAP 8.2
transplanted, using the same `ρ_0` identity NLAlib proved (`add_div_sub_add_sqrt_sq_sub_one_eq`). Mathlib has `slitPlane`,
`Complex.differentiableAt_log` and `DifferentiableAt.cpow_const`. Consumers: `slq-error` with f = log (log-determinant) and
f = x^{−1/2}; Krylov `A^{−1/2}b`; `sign-polynomial-approx`.

**`sign-polynomial-approx`.** (`next`, 1, prove)
For `0 < γ < 1` and `1 < r < (1+γ)/(1−γ)`, there is an odd `p(x) = x q(x²)` of degree ≤ 2n+1 with
`|sgn x − p(x)| ≤ 2 m_r^{−1/2} r^{−n}/(r−1)` on `γ ≤ |x| ≤ 1` (the x^{−1/2} bound on `[γ², 1]`). With `r = 1+γ`,
`m_r = γ²(3+γ)/4` and the bound is `≤ (4/(√3 γ²))(1+γ)^{−n}`, i.e. degree `O(γ^{−1} log(1/(γε)))`. As `r ↑ ρ_0` the
base tends to `(1−γ)/(1+γ)` per degree-2 step, the exponential base of Eremenko–Yuditskii's sharp asymptotics (ey07 Thm 1;
pin its constant before adding it as an assumed variant). A variant that is also `|p| ≤ 1` on all of [−1,1] (stable
projectors, Gilyén–Su–Low–Wiebe 2019) is later. Consumers: spectral projectors and principal component projection (fmms16),
eigenvalue counting, gap-dependent block Krylov.

**`sign-approx-lower-bound`.** (`next`, 1, prove)
If `|p| ≤ M` on [−1,1], `|p − sgn| ≤ ε < 1` on `γ ≤ |x| ≤ 1` and `deg p ≤ q`, then `qM ≥ (1−ε)√(1−γ²)/γ`. Proof: MVT on `[−γ,γ]`
plus NLAlib's Bernstein inequality. This shows the 1/γ order is optimal.

**`inverse-approx-lower-bound`.** (`next`, 1, prove)
If `deg p < q` and `|p − 1/x| ≤ ε` on `[a,b]`, then `ε ≥ 1/(b T_q((b+a)/(b−a))) ≥ (1/b)((√b−√a)/(√b+√a))^q`. Proof: apply
`chebyshev-minimax` to `1 − x p`. The existing `inverse-polynomial-approx` is sharp up to `2b/a`. Consumers: optimality of the √κ
rates (CG, Chebyshev iteration, sketch-and-precondition iteration counts).

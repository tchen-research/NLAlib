```lean
/-- The eigenvalues of the compression `Qᴴ A Q` (`Q` with orthonormal columns) lie in every
interval `[a, c]` containing the eigenvalues of `A`. Parlett (1998), Thm 10.1.1 (weak form). -/
theorem Matrix.IsHermitian.eigenvalues_conjTranspose_mul_mul_same_mem_Icc
    {A : Matrix n n 𝕜} (hA : A.IsHermitian) {Q : Matrix n k 𝕜} (hQ : HasOrthonormalCols Q)
    {a c : ℝ} (hspec : ∀ i, hA.eigenvalues i ∈ Set.Icc a c) (j : k) :
    (Matrix.isHermitian_conjTranspose_mul_mul Q hA).eigenvalues j ∈ Set.Icc a c
```

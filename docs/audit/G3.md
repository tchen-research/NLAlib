# Audit G3: Krylov, estimation and solvers

Scope: atlas areas `krylov`, `estimation` and `solvers`, and modules `NLAlib/Krylov/**`, `NLAlib/Estimation/**` and
`NLAlib/Solvers/**`. It also covers how these consume the polynomial layer `NLAlib/Polynomial/**` and
`mem_krylovSpace_iff`. This is a read-only audit, dated 2026-10-10.

How this was checked:
- The atlas (152 results) and `atlas/declarations.json` (1300 declarations, 5 with `sorry`, all in
  `Sketching/JL.lean`) were queried with `python3`.
- Reuse is the transitive in-degree of `depends_on`, written `tin`.
- Every Lean file in scope was read, along with `Polynomial/{Basic,Minimax,Approximation}.lean`,
  `Gaussian/Extreme/ChiSquare.lean` and `Estimation/HansonWright.lean`.
- Mathlib under `.lake/packages/mathlib/Mathlib` was searched with `grep -rniE` for every item in section A
  and for every Mathlib name cited below.

Cross-references: G0's `docs/audit/G0.md` already proposes three things G3 needs.
- A3 `bernstein-ellipse-approx`.
- C5, the polynomial calculus of symmetric matrices.
- Moving `quadForm` down to the Matrix layer.

This report uses those exact statements and does not repeat them.

### A2. new `cg-hestenes-stiefel`: the CG recurrence computes the Krylov A-norm minimiser (optional; tin 2 via `nystrom-pcg` as an algorithm)

- **Statement:** for SPD `A`, the Hestenes–Stiefel recurrence produces, at every step `q`, the minimiser of
  `φ` over `x₀ + K_q(A, r₀)`.
- **Lean, in `NLAlib/Krylov/CG.lean`.** The state is the triple `(x, r, p)`. Lean's convention `0/0 = 0` makes
  breakdown harmless: once `r_k = 0` we get `β = 0`, `p = 0` and `α = 0/0 = 0`, so the iterate stays at the
  solution. No `r_j ≠ 0` hypothesis is therefore needed.

  ```lean
  /-- One Hestenes–Stiefel step on `(x, r, p)`. -/
  def cgStep (A : Matrix n n ℝ) (s : (n → ℝ) × (n → ℝ) × (n → ℝ)) : (n → ℝ) × (n → ℝ) × (n → ℝ) :=
    let (x, r, p) := s
    let α := (r ⬝ᵥ r) / (p ⬝ᵥ (A *ᵥ p))
    let r' := r - α • (A *ᵥ p)
    (x + α • p, r', r' + ((r' ⬝ᵥ r') / (r ⬝ᵥ r)) • p)

  /-- `q` CG steps from `x₀` (with `r₀ = p₀ = c − A x₀`). -/
  def cgIter (A : Matrix n n ℝ) (c x₀ : n → ℝ) (q : ℕ) : n → ℝ :=
    ((cgStep A)^[q] (x₀, c - A *ᵥ x₀, c - A *ᵥ x₀)).1

  /-- SCAFFOLD: cg-hestenes-stiefel. Trefethen–Bau 1997, Thm 38.1–38.2; Saad 2003, §6.7. -/
  theorem isCGIterate_cgIter {A : Matrix n n ℝ} (hA : A.PosDef) (c x₀ : n → ℝ) (q : ℕ) :
      IsCGIterate A c x₀ q (cgIter A c x₀ q)
  ```

  `IsCGIterate` is the definition in C3. TB97 states it for `x₀ = 0`. The general `x₀` follows by translation.
- **Confidence:** high. The one thing to verify is the `0/0` breakdown argument above, which is easy to
  check by hand.
- **Mathlib:** absent (grep `conjugate.?gradient|hestenes` finds nothing).
- **Unlocks:** B2 (algorithmic CG κ-bound) and B3 (`nystrom-pcg`).
- **Full proof:** difficulty 4. It is a simultaneous induction on `r_i ⊥ r_j`, `p_iᵀAp_j = 0` and
  `span{r_i} = span{p_i} = K`.
- **Recommendation:** assume only if an algorithmic consumer is wanted soon. The variational CG of C3 needs none of this.

### A3. `random-start-power`, KW92 expectation form (optional; tin 0; medium-low confidence on the constants)

- **Statement:** with `u` uniform on the sphere (equivalently, Gaussian) and PSD `A`, let `ε_k` be the relative
  error `(λ₁ − ξ_k)/λ₁` of the power or Lanczos estimate after `k` steps. Then:
  - `E[ε_k^{pow}] ≤ 0.871 ln(n)/(k−1)`;
  - `E[ε_k^{Lan}] ≤ 2.575 (ln n)²/(k−1)²`;
  - `P(ε_k^{pow} ≥ ε) ≤ 0.824 √n (1−ε)^{k−1/2}`;
  - `P(ε_k^{Lan} ≥ ε) ≤ 1.648 √n e^{−√ε(2k−1)}`.
- **Source:** Kuczyński–Woźniakowski 1992 [`kw92`]. The atlas cites Thm 3.1 and 4.2. The exact ranges of `k` and `n`
  and the step-count convention (whether `ξ_k` uses `A^{k−1}b` or `A^k b`) must be checked against the paper.
- **Recommendation: do not scaffold.** C16 gives an explicit high-probability bound of the same order from proved
  pieces, with constants we control. If the KW92 form is ever wanted, state it in `NLAlib/Estimation/RandomStart.lean`
  with the step convention written into the docstring.
- **Mathlib:** absent.

### A4. new `nystrom-preconditioner-condition`: Frangella–Tropp–Udell 2023 (optional; unlocks `nystrom-pcg`)

- **Statement:** take PSD `A`, `μ > 0`, a Gaussian test matrix `Ω ∈ ℝ^{n×ℓ}`, and the Nyström
  approximation `Â = UΛ̂Uᵀ = (AΩ)(ΩᵀAΩ)^†(AΩ)ᵀ` (rank `ℓ`). Define the preconditioner
  `P = (λ̂_ℓ+μ)^{−1} U(Λ̂+μI)Uᵀ + (I − UUᵀ)` and the effective dimension `d_eff(μ) = tr(A(A+μI)^{−1})`.
  - **Deterministic part (Prop 5.3):** `κ(P^{−1/2}(A+μI)P^{−1/2}) ≤ (λ̂_ℓ + μ + ‖A − Â‖)/μ`.
  - **Randomized part (Thm 5.1):** if `ℓ = 2⌈1.5 d_eff(μ)⌉ + 1`, then `E κ < 28`.
- **Source:** FTU23, SIMAX 44(2). The source is not yet in `atlas.sources`; add `ftu23`.
- **Confidence:** medium. The constants `28` and `1.5`, and the theorem numbers, need to be checked.
- **Recommendation:** prove the deterministic part rather than assume it. It is an eigenvalue calculation, at
  difficulty 3. Assume only the randomized part, which reduces to a spectral-norm Nyström error bound and belongs to G2
  (`nystrom-randomized` is Frobenius and nuclear only today).
- **Mathlib:** absent. NLAlib has no symmetric Nyström definition yet: only `rawGeneralizedNystrom`, in
  `LowRank/RawNystromBridge.lean`.
- **Where:** `NLAlib/Solvers/NystromPCG.lean`.
- **Full proof:** difficulty 4.

### A5. `hutchinson-tail`, Cortinovis–Kressner sharp constants (optional; tin 1)

- **Statement (Gaussian):** for symmetric `A` and `m` independent Gaussian vectors,
  `P(|tr_m(A) − tr A| ≥ ε) ≤ 2 exp(−m ε² / (4‖A‖_F² + 4ε‖A‖))`.
- **Source:** CK21 Thm 1. The Rademacher analogue is Thm 3, with Hanson–Wright constants.
- **Confidence:** medium, on the exact denominators.
- **Recommendation: not needed.** C6 proves the same shape now from the proved `hanson_wright_mgf`, with the
  constant `1/(256e²)`. Assume CK21 only if a consumer needs the sharp constant.
- **Related:** `chi-square-upper-tail` and Laurent–Massart Lemma 1 (G1; source `lm00`) are **provable**, so they
  should not be assumed. `integral_exp_neg_mul_sum_sq_pi_gaussianReal` gives `E e^{sχ²} = (1−2s)^{−d/2}`
  for `s < 1/2`, and Chernoff then gives the upper tail at difficulty 2 (G1's item).

**Pointer, not a G3 assumption:** the high-probability `hutchpp` with `log(1/δ)` dependence also needs a Frobenius tail
for the Gaussian range finder (HMT 2011 §10.3; owned by G2). The constant-probability `O(1/ε)` Hutch++ needs only the
proved expectation bound (C11).

### C3. `cg-convergence`, variational CG (tin 2: `nystrom-pcg`, B2)

In `NLAlib/Krylov/CG.lean`:

```lean
def cgObjective (A : Matrix n n ℝ) (c x : n → ℝ) : ℝ := quadForm A x / 2 - c ⬝ᵥ x

/-- `x` is a `q`-th CG iterate for `A x = c` from `x₀`. Trefethen–Bau 1997, Thm 38.2 (variational form). -/
def IsCGIterate (A : Matrix n n ℝ) (c x₀ : n → ℝ) (q : ℕ) (x : n → ℝ) : Prop :=
  x - x₀ ∈ krylovSpace A (c - A *ᵥ x₀) q ∧
    ∀ y ∈ krylovSpace A (c - A *ᵥ x₀) q, cgObjective A c x ≤ cgObjective A c (x₀ + y)

theorem exists_isCGIterate {A : Matrix n n ℝ} (hA : A.PosDef) (c x₀ : n → ℝ) (q : ℕ) :
    ∃ x, IsCGIterate A c x₀ q x

/-- Polynomial form, TB97 Thm 38.3. -/
theorem quadForm_sub_le_of_isCGIterate_of_poly {A : Matrix n n ℝ} (hA : A.IsHermitian)
    (hpsd : ∀ i, 0 ≤ hA.eigenvalues i) {c x₀ xs x : n → ℝ} (hxs : A *ᵥ xs = c) {q : ℕ}
    (hx : IsCGIterate A c x₀ q x) {p : ℝ[X]} (hp : p.degree ≤ q) (hp0 : p.eval 0 = 1) {M : ℝ}
    (hM : ∀ i, |p.eval (hA.eigenvalues i)| ≤ M) :
    quadForm A (x - xs) ≤ M ^ 2 * quadForm A (x₀ - xs)

/-- κ-bound, TB97 Thm 38.5; GM10 Ch. 8. `(√b−√a)/(√b+√a) = (√κ−1)/(√κ+1)` with `κ = b/a`. -/
theorem quadForm_sub_le_of_isCGIterate {A : Matrix n n ℝ} (hA : A.IsHermitian) {a b : ℝ}
    (ha : 0 < a) (hab : a < b) (hspec : ∀ i, hA.eigenvalues i ∈ Set.Icc a b)
    {c x₀ xs x : n → ℝ} (hxs : A *ᵥ xs = c) {q : ℕ} (hx : IsCGIterate A c x₀ q x) :
    quadForm A (x - xs) ≤ (2 * ((√b - √a) / (√b + √a)) ^ q) ^ 2 * quadForm A (x₀ - xs)
```

- **From:** C1, `mem_krylovSpace_iff_degree`, `abs_eval_chebyshevResidual_le_two_mul_pow`,

### C5. `lanczos-gauss-quadrature`: exactness and error (tin 1: `slq-error`)

```lean

Deviation: any orthonormal `Q` with `K_q(A,b) ⊆ range Q`, so neither tridiagonality nor the Lanczos recurrence is

theorem dotProduct_aeval_mulVec_eq_of_krylovSpace_le {A : Matrix n n ℝ} (hA : A.IsSymm)
```

- **Sketch:** set `P = QQᵀ` and `B = QᵀAQ`.

  - `‖Qᵀb‖ ≤ ‖b‖` by `specNorm_le_one_of_orthonormal`.

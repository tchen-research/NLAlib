## Generalisation (finding matrix_spectral#0, matrix_norms#32 core)

* `NLAlib.singularValues` (Spectral/SVD.lean) now takes
  `{𝕜} [RCLike 𝕜] {m n} [Fintype m] [Fintype n] [DecidableEq n] (A : Matrix m n 𝕜)`; body unchanged,
  `singularValues_eq_linearMap` still `rfl`, every Fin/ℝ use elaborates unchanged.
* Generalised to the same RCLike/Fintype context (proofs unchanged): `singularValues_eq_linearMap`,
  `_nonneg`, `_antitone`, `_ne_zero_iff`, `_pos_iff`, `_eq_zero_of_rank_le`.
* `sq_singularValues_eq_eigenvalues₀` is now the RCLike/Fintype statement
  `singularValues A i ^ 2 = (isHermitian_conjTranspose_mul_self A).eigenvalues₀ i`,
  `i : Fin (card n)` (finding #5). It replaces the old Fin form (explicit `hAA`, `Fin.cast`),
  `sq_toEuclideanLin_singularValues_eq_eigenvalues₀`, and `complexSingularValues_sq`.
  Fin callers (CourantFischer, CompressionDeterminant) pass `Fin.cast (Fintype.card_fin n).symm _`.
* Left on `Fin` (they need `Fin` ordering): `rectDiag`, `IsSVD`, `exists_isSVD`, `IsSVD.*`,
  `frobSq_eq_sum_sq_singularValues`, `singularValues_eq_of_eq_mul_rectDiag_mul`,
  `singularValues_eq_zero_of_{height,width,min}_le`, `rank_eq_card_singularValues_ne_zero`.

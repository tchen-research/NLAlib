### A1. Volumetric ε-net of the sphere
- **atlas id:** `epsilon-net-norm` (covering half). Unlocks `epsilon-net-norm` and then
  `subgaussian-matrix-norm` (trans 1), plus B2 (new).
- **Statement:** the unit sphere of `ℝⁿ` has an ε-net, contained in the sphere, with at most
  `(1 + 2/ε)ⁿ` points.
- **Lean:**
  ```lean
  /-- SCAFFOLD: epsilon-net-norm. -/
  theorem exists_finset_sphere_net (n : ℕ) {ε : ℝ} (hε : 0 < ε) :
      ∃ N : Finset (Fin n → ℝ), (∀ x ∈ N, x ⬝ᵥ x = 1) ∧ (N.card : ℝ) ≤ (1 + 2 / ε) ^ n ∧
        ∀ y : Fin n → ℝ, y ⬝ᵥ y = 1 → ∃ x ∈ N, (x - y) ⬝ᵥ (x - y) ≤ ε ^ 2
  ```
  It is stated with `dotProduct` on purpose. `Fin n → ℝ` carries the sup metric, so a
  `Metric.coveringNumber` version must be stated on `EuclideanSpace ℝ (Fin n)` (optional
  companion: `Metric.coveringNumber ⟨ε, hε.le⟩ (Metric.sphere (0 : EuclideanSpace ℝ (Fin n)) 1)
  ≤ ⌊(1 + 2/ε)^n⌋₊`).
- **Source:** Vershynin 2012, Lem 5.2; Vershynin 2018, Cor 4.2.13.
- **Confidence:** high. Degenerate cases: for `n = 0` the sphere is empty, so `N = ∅` and the
  bound is 1. Large ε is fine. Using `≤ ε²` (closed net) is standard.
- **Module:** `NLAlib/ForMathlib/MeasureTheory/CoveringNumber.lean` (the volumetric argument is
  general), re-exported in vocabulary form from `NLAlib/Matrix/Nets.lean`.
- **Full proof:** difficulty 3. Take a maximal ε-separated set (Mathlib
  `maximalSeparatedSet`, `coveringNumber_le_packingNumber`). The disjoint balls of radius ε/2
  lie inside `ball 0 (1 + ε/2)`; then use `Measure.addHaar_ball` scaling. HighDimProb's
  `coveringNumber_euclideanBall_le` can be ported, but HighDimProb is not a lake dependency.

### A2. Concentration of convex Lipschitz functions of a Rademacher vector
- **atlas id:** new, `rademacher-convex-concentration` (area `concentration-scalar`). Unlocks the
  SRHT row-norm flattening lemma (B4), hence `srht-ose`. It also gives concentration of
  `‖Σ εᵢ aᵢ‖` for Rademacher sketches.
- **Statement:** if `f : ℝⁿ → ℝ` is convex and L-Lipschitz (Euclidean) and ε is a Rademacher
  vector, then `P(f(ε) ≥ E f(ε) + L t) ≤ e^{−t²/8}`.
- **Lean:**
  ```lean
  /-- SCAFFOLD: rademacher-convex-concentration. -/
  theorem measure_integral_add_le_of_convexOn_rademacher {n : ℕ} (f : (Fin n → ℝ) → ℝ)
      (hf : ConvexOn ℝ Set.univ f) (L : ℝ) (hL : 0 < L)
      (hLip : ∀ x y, |f x - f y| ≤ L * √(∑ i, (x i - y i) ^ 2)) (t : ℝ) (ht : 0 ≤ t) :
      (Measure.pi fun _ : Fin n => rademacherMeasure)
          {x | (∫ y, f y ∂(Measure.pi fun _ : Fin n => rademacherMeasure)) + L * t ≤ f x}
        ≤ ENNReal.ofReal (Real.exp (-t ^ 2 / 8))
  ```
- **Source:** Tropp 2011 (atlas `tropp11`), Prop 2.1, from Ledoux 2001 (`ledoux01`), eq. (1.9) /
  Cor 4.10: the `[0,1]ⁿ` bound `e^{−t²/2}` rescaled to `[−1,1]ⁿ`.
- **Confidence:** medium-high. The constant 8 is the mean-centred LSI form for the cube of side 2.
  Talagrand's convex-distance version is about the *median*, with `4e^{−t²/16}`; do not mix the
  two. Convexity is essential: the bound fails for general Lipschitz `f` on the cube.
- **Module:** `NLAlib/Concentration/Scalar/RademacherConvex.lean`. This first needs
  `rademacherMeasure` moved from `Estimation/HutchinsonLaws.lean` (layer 4) to
  `Concentration/Matrix/Defs/ScalarLaws.lean` (layer 1, next to `IsRademacher`); see C notes.
- **Full proof:** difficulty 4. Use `entropy_pi_le_sum_integral_entropy_update` (proved), a 1-D
  two-point entropy inequality for convex `f`, and Herbst
  (`integral_exp_mul_le_exp_of_entropy_le`, proved).

### A3. McDiarmid's bounded-differences inequality
- **atlas id:** `mcdiarmid` (trans 0 today; consumers would be sampling-based sketches, U-statistics
  and `‖Σ εᵢaᵢ‖` bounds).
- **Lean:**
  ```lean
  /-- SCAFFOLD: mcdiarmid. -/
  theorem measure_integral_add_le_of_bounded_differences {ι : Type*} [Fintype ι]
      {X : ι → Type*} [∀ i, MeasurableSpace (X i)] (ν : ∀ i, Measure (X i))
      [∀ i, IsProbabilityMeasure (ν i)] (f : (∀ i, X i) → ℝ) (hf : Measurable f) (c : ι → ℝ)
      (hc : ∀ (x y : ∀ i, X i) (i : ι), (∀ j, j ≠ i → x j = y j) → |f x - f y| ≤ c i)
      (t : ℝ) (ht : 0 ≤ t) :
      (Measure.pi ν) {x | (∫ y, f y ∂Measure.pi ν) + t ≤ f x}
        ≤ ENNReal.ofReal (Real.exp (-2 * t ^ 2 / ∑ i, c i ^ 2))
  ```
- **Source:** Vershynin 2018, Thm 2.9.1; McDiarmid 1989.
- **Confidence:** high. Degenerate case `Σcᵢ² = 0`: `f` is constant, and Lean's `/0` gives bound 1,
  which is correct at `t = 0`. Integrability follows (bounded differences imply `f` is bounded).
- **Module:** `NLAlib/Concentration/Scalar/McDiarmid.lean`.
- **Full proof:** difficulty 3–4. Use the Doob martingale on the product space with Mathlib
  Azuma–Hoeffding. It also needs a *conditional* Hoeffding lemma for a predictable interval of
  length `cᵢ`, which is not in Mathlib. Mathlib's Azuma also requires `StandardBorelSpace`.

### A4. Non-commutative Khintchine (moment form)
- **atlas id:** `noncommutative-khintchine` (trans 0).
- **Lean:**
  ```lean
  /-- SCAFFOLD: noncommutative-khintchine. -/
  theorem integral_trace_pow_series_le {Ω : Type*} [MeasurableSpace Ω] (μ : Measure Ω)
      [IsProbabilityMeasure μ] {d N : ℕ} [NeZero d] (A : Fin N → Matrix (Fin d) (Fin d) ℂ)
      (hA : ∀ k, (A k).IsHermitian) (g : Fin N → Ω → ℝ) (hMeas : ∀ k, Measurable (g k))
      (hIndep : iIndepFun g μ)
      (hLaw : (∀ k, IsStandardGaussian μ (g k)) ∨ ∀ k, IsRademacher μ (g k)) (p : ℕ) :
      ∫ ω, (Matrix.trace ((∑ k, g k ω • A k) ^ (2 * p))).re ∂μ
        ≤ ((2 * p - 1).doubleFactorial : ℝ) * (Matrix.trace ((∑ k, A k ^ 2) ^ p)).re
  ```
  The atlas `√(2p−1)` form is the corollary `(2p−1)!! ≤ (2p−1)^p`.
- **Source:** Buchholz 2001, Thm 5 (Rademacher, sharp constant); Gaussian by the Wick/genus
  expansion. Tropp 2015 §4.8 cites it but is not a theorem source.
- **Confidence:** high for natural `p`. The atlas hypothesis "`p ≥ 1`" must mean `p ∈ ℕ`:
  `tr Z^{2p}` for indefinite Hermitian `Z` is not defined for real `p`.
- **Module:** `NLAlib/Concentration/Matrix/Series/Khintchine.lean`.
- **Full proof:** difficulty 4–5.

### A5. Matrix Freedman
- **atlas id:** `matrix-freedman` (trans 0).
- **Lean (shape):** `X : ℕ → Ω → Matrix (Fin d) (Fin d) ℂ`, Hermitian, adapted to `ℱ`, with
  `μ[X (k+1) | ℱ k] =ᵐ 0` and `lambdaMax (X k ω) ≤ R`. Let `W k = ∑ j ≤ k, μ[X j ^ 2 | ℱ (j-1)]`.
  Then `μ {ω | ∃ k ≤ n, t ≤ lambdaMax (∑ j ∈ range (k+1), X j ω) ∧ spectralNorm (W k ω) ≤ σ²}

- **Source:** Tropp 2011, *Freedman's inequality for matrix martingales*, ECP, Thm 1.1. The atlas
  cites "tropp15 §6.5 notes"; replace with this.
- **Confidence:** medium. The statement is standard, but the Lean indexing of the predictable
  quadratic variation and the `k = 0` term need care.
- **Module:** `NLAlib/Concentration/Matrix/Freedman.lean`.
- **Full proof:** difficulty 5 (Lieb's theorem is proved here; the supermartingale argument is new).

(`haar-orthogonal`, `isserlis` and `subgaussian-matrix-norm` are omitted from A on purpose. The
first two are provable outright at difficulty 3 with no consumers. `subgaussian-matrix-norm`

### B2. Operator norm of a matrix with sub-Gaussian bilinear marginals (new, `subgaussian-spec-norm`)
- **Lean:**
  ```lean
  theorem measure_lt_specNorm_le_of_hasSubgaussianMGF {Ω : Type*} [MeasurableSpace Ω]
      {μ : Measure Ω} [IsProbabilityMeasure μ] {m n : ℕ} (A : Ω → Matrix (Fin m) (Fin n) ℝ)
      (c : ℝ≥0) (hA : ∀ (x : Fin n → ℝ) (y : Fin m → ℝ), x ⬝ᵥ x = 1 → y ⬝ᵥ y = 1 →
        HasSubgaussianMGF (fun ω => y ⬝ᵥ (A ω).mulVec x) c μ) (t : ℝ) (ht : 0 ≤ t) :
      μ {ω | 2 * (√(2 * Real.log 9 * (m + n) * c) + √c * t) < specNorm (A ω)}
        ≤ ENNReal.ofReal (Real.exp (-t ^ 2 / 2))
  ```
  The inequality is **strict**. With `≤` the statement is false when `c = 0` (then `A = 0` a.s.
  and the event is everything).
- **Follows from:** A1 at ε = 1/4 (nets of size `9ⁿ`, `9ᵐ`); the bilinear part of C8
  (`‖A‖ ≤ 2 max ⟨Ax, y⟩`); `HasSubgaussianMGF.measure_ge_le`; `measure_biUnion_le`.
- **Sketch:** set `u = √c(√(2(m+n) ln 9) + t)`, so `u² ≥ c(2(m+n) ln 9 + t²)`. The union bound
  gives `9^{m+n} e^{−u²/2c} ≤ e^{−t²/2}`. No measurability is needed (outer measure).
- **Corollary (same file):** independent entries with `HasSubgaussianMGF (A i j) c`. The bilinear
  marginal has proxy `c Σ yᵢ²xⱼ² = c` by Mathlib `HasSubgaussianMGF.sum_of_iIndepFun`. This
  covers Rademacher entries via C5.
- **Source:** Vershynin 2018, Thm 4.4.5 (with constants made explicit).
- **Difficulty:** 2.
- **File:** `NLAlib/Gaussian/SubGaussianNorm.lean` (layer 2, area `gaussian-subgaussian`).

### B4. SRHT row-norm flattening (new, home area `sketching-ose`, owned by G2)
- **Statement:** for `U` (n×d) with orthonormal columns, normalized Walsh–Hadamard `H` and
  Rademacher `D`: `P(max_j ‖e_jᵀ H D U‖ ≥ √(d/n) + √(8 log(n/δ)/n)) ≤ δ`.
- **Follows from:** A2 with `f(ε) = ‖e_jᵀ H diag(ε) U‖`. It is convex, with `L = 1/√n` because
  `|H_{jk}| = 1/√n`. `E f ≤ √(E f²) = √(d/n)` via `integral_le_of_integral_sq_le`; finish with a
  union bound over `j`.
- **Source:** Tropp 2011, Lem 3.3.
- **Difficulty:** 2 (given a Hadamard definition).
- **Unlocks:** `srht-ose` (together with C4).

### C1. `chi-square-upper-tail`: Chernoff (Dasgupta–Gupta) and Laurent–Massart forms
- **trans:** 6.
- **Lean:**
  ```lean
  theorem measure_le_sum_sq_le_gaussianReal {d : ℕ} {ε : ℝ} (hε : 0 ≤ ε) :
      (Measure.pi fun _ : Fin d => gaussianReal 0 1) {g | (1 + ε) * d ≤ ∑ i, g i ^ 2}
        ≤ ENNReal.ofReal (Real.exp (-((d : ℝ) / 2) * (ε - Real.log (1 + ε))))
  theorem measure_add_two_sqrt_mul_add_le_sum_sq_le_gaussianReal {d : ℕ} {x : ℝ} (hx : 0 ≤ x) :
      (Measure.pi fun _ : Fin d => gaussianReal 0 1) {g | d + 2 * √(d * x) + 2 * x ≤ ∑ i, g i ^ 2}
        ≤ ENNReal.ofReal (Real.exp (-x))
  ```
- **Follows from:** `integral_exp_neg_mul_sum_sq_pi_gaussianReal` (the Laplace transform, already
  proved for every `u > 0`, i.e. every mgf argument `< 1/2`); Mathlib `measure_ge_le_exp_mul_mgf`;
  `Integrable.fintype_prod` with `integrable_exp_neg_mul_sq` for integrability;
  `Real.quadratic_le_exp_of_nonneg`.
- **Sketch:**
  1. Chernoff at `s = ε/(2(1+ε))`. The Laplace transform at `u = 1/(1+ε)` gives
     `e^{−εd/2}(1+ε)^{d/2}`.
  2. Laurent–Massart: put `a = √(x/d)` and `ε = 2a + 2a²`. Then `e^{2a} ≥ 1 + 2a + 2a²` gives
     `(d/2)(ε − log(1+ε)) ≥ x`.
  3. `d = 0` is direct (the event is `{2x ≤ 0}`).
- **Optional variant:** `P(√χ²_d ≥ √d + t) ≤ e^{−t²/2}`, from `gaussian_concentration_pi`
  (f = Euclidean norm, L = 1) and `integral_le_of_integral_sq_le`. Difficulty 1.
- **Source:** Laurent–Massart 2000, Lem 1. The Chernoff form is the computation in the proof of
  Dasgupta–Gupta 2003, Lem 2.2(b). Note that Lem 2.2 itself is about projections of a random
  *unit* vector.
- **Difficulty:** 2.
- **File:** `NLAlib/Gaussian/Extreme/ChiSquare.lean`.

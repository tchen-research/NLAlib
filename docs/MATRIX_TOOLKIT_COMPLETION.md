# Matrix toolkit completion: scope and verification

This change closes the 25 matrix-toolkit contracts selected before the latest first-course algorithm update. It incorporates upstream main `e8c22ae` and reuses its proved QR, inverse and least-squares APIs. The supplied operator derivations and compact variational Schur–Horn argument are proof sources; the formal statements preserve the original real-matrix contracts, exact constants, converse directions and degenerate cases.

## Corrections and integration

- Rectangular Kronecker singular-value lists require zero multiplicities. The native domain-side multiset equality is exact; thin lists require `min(mp,nq) - min(m,n)min(p,q)` additional zeros.
- Attained distance to singularity and positive-definite extreme-eigenvalue ratios require positive dimension. Empty matrices retain the total condition-number convention `κ(0)=0`.
- Davis–Kahan population bounds cite Yu–Wang–Samworth Theorem 2 and now accept arbitrary valid invariant top frames, including tied perturbed choices. The Frobenius proof uses actual finite spectral weights.
- The rectangular Mirsky corollary evaluates one fixed genuine matrix norm through its induced symmetric gauge; it does not assume the desired norm comparison.
- Least-squares bounds use the actual unique Moore–Penrose minimizers and derive perturbed full rank. They include the advertised coefficient, the stronger residual coefficient `1+κ`, an actual geometric angle, and an explicit quadratic first-order remainder.
- Shared CFC, eigenvalue-norm and Moore–Penrose rank helpers are reused or moved to their correct lower layer, preserving public names and existing imports. The complex Cholesky pivot proof is moved to layer 0 with a compatibility import at its former path.
- Coordinate least-squares wrappers preserve the incoming total real division conventions; the complete joint contract requires a nonzero actual solution, as the original theorem does.
- New first-course algorithms and their separately named scaffolds are separate catalogue results. A full tag for one of these 25 contracts does not certify an unrelated algorithm scaffold.
